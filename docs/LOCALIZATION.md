# Localization policy

FinalTECH is maintained English-first in this fork.

- `src/main/resources/language/en-US.yml` is the default player-facing locale.
- `zh-CN.yml` and `zh-TW.yml` are retained as intentional optional translations.
- Source code, configuration comments, documentation, logs, and other maintained project text should remain English.
- Existing item IDs, configuration keys, persistent data keys, and serialized identifiers are not renamed solely for localization.
- Where terminology overlaps with FinalTECH, use the established English names from LobbyTech-MC/FinalTech rather than introducing new literal translations.

Preferred established terms include **Equivalent Concept**, **Justifiability**, **Entropy Seed**, **Entropy Cleaner**, **Item Phony**, **Ordered Dust**, **Unordered Dust**, and **Matrix Reactor**.
