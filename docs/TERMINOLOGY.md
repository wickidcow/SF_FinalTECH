# FinalTECH English terminology

This fork follows established English naming from the maintained FinalTECH lineage wherever an existing term is available.

| Internal ID / concept | Preferred English term |
| --- | --- |
| `_FINALTECH_EQUIVALENT_CONCEPT` | Equivalent Concept |
| `_FINALTECH_JUSTIFIABILITY` | Justifiability |
| `_FINALTECH_ENTROPY_SEED` | Entropy Seed |
| `_FINALTECH_ENTROPY_CLEANER` | Entropy Cleaner |
| `_FINALTECH_PHONY` | Phony |
| `_FINALTECH_ORDERED_DUST` | Ordered Dust |
| `_FINALTECH_UNORDERED_DUST` | Unordered Dust |
| `_FINALTECH_MATRIX_REACTOR` | Matrix Reactor |

Do not rename internal IDs, configuration keys, persistent-data keys, or serialized identifiers solely to match display names. This glossary is for player-facing text, documentation, logs, and future translations.
